# FFmpeg Firequalizer FIR FILTER

Customizable Lua equalizer controller for **mpv** using FFmpeg `firequalizer`.

### Features

* 20-band EQ
* 60-band EQ
* 4096-band interpolated EQ
* Freely customizable band toggles
* Custom EQ presets

### Origin

Based on the equalizer concept and preset data from **VLC media player**, substantially modified and extended for FFmpeg `firequalizer` and mpv Lua.

**Documentation:**
https://ffmpeg.org/ffmpeg-filters.html#firequalizer
